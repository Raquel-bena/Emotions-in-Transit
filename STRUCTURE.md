# Emotions in Transit - Estructura de Proyecto

## 📁 Estructura Principal
- **/visuals** → Visualizaciones interactivas
  - /processing → Sketches en Processing (Java)
  - /touchdesigner → Proyectos TouchDesigner
  - /webgl → Visualizaciones web con Three.js/p5.js

- **/sound** → Sistema de audio
  - /samples → Archivos de audio pregrabados
  - /generative → Síntesis de audio en tiempo real
  - /configs → Configuraciones de mapeo emocional

- **/src** → Código fuente de la aplicación web
  - /components → Componentes React/JSX
  - /utils → Funciones utilitarias
  - /styles → Estilos CSS/SCSS
  - /lib → Librerías personalizadas

- **/public** → Assets públicos
  - /assets → Imágenes, sonidos, fuentes

- **/docs** → Documentación
  - /technical → Documentación técnica
  - /research → Investigación artística y teórica
  - /installation → Guías de instalación física

- **/config** → Configuraciones del sistema
- **/scripts** → Scripts de utilidad y automatización
